Comparison between getElementById and querySelector

getElementById and querySelector are both ways to interact with a webpage and retrieve elements from it. At a glance they both seem very similar, but they have some key differences in how they work and what they can do.


The first method that I will go over is getElementById. This method strictly retrieves an element by its id, as the name states.. When you use getElementById it will only look at the id attributes that are on the webpage, making it much faster and efficient

The next method is querySelector. This method can be used when trying to select from a CSS selector. Meaning it could be an id, class or a tag name.
